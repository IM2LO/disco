# Disco1

Version autonome avec planning, heures travaillées et prévision de paie : interface originale conservée, journées confirmées/prévisionnelles, pauses, affectations, badgeages réels et import/export JSON incluant les paramètres de paie.

Ouvrir index.html ou https://im2lo.github.io/disco/. Les réglages définissent la période et les jours de repos. Les exports de shifts de Cap Contrat peuvent être importés.

Stockage local propre à Disco1, indépendant de Cap Contrat.
